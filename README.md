# Open Photos

Monorepo for the Open Photos project.

## Structure
- `client/` React app
- `server/` API + background jobs
- `packages/` shared libraries (types, utils, SDK)
- `infra/` deployment notes and scripts
- `docs/` product and architecture docs

## Docs
- `MASTERPLAN.md` high-level plan and roadmap
- `docs/ARCHITECTURE.md` system architecture and code layout
- `docs/INFRA_CHECKLIST.md` provider setup checklist
